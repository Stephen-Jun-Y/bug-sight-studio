# BugSight 项目功能核对表

> 说明：本清单基于当前项目代码现状整理，用于逐项核对“保留 / 删除 / 接后端 / 继续 mock / 补充业务规则”。

## 状态说明

- `已打通`：前后端/模型已经真实接通
- `半打通`：后端已有能力，但前端未完整接入
- `原型`：主要是前端静态页面或本地状态演示
- `待实现`：数据库或规划有预留，但尚未形成完整业务能力

## 使用方式

你可以在每项后面补：
- `保留`
- `删除`
- `接后端`
- `继续 mock`
- `要补充：xxx`
